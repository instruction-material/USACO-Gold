# Fenwick point updates and prefix/range sums

Gold Unit 4 uses this authored algorithm checkpoint for additive point updates and inclusive sums. `starter/` contains a compiling learner scaffold with four unfinished tasks; `solution/` contains the complete validated reference. Both contain Main.java, README.md and sample.in and can be saved as separate project attempts.

The standalone role guides include the contract, prerequisites, trace, native commands and independent checks. Public indices remain zero-based, matching the original demonstration; internal slot zero is unused. This pack practices sums with point additions. Its bounds and operation format are course-authored, not an official contest problem.

`legacy/Main.java` preserves the original fixed 11-value demonstration byte-for-byte from source commit 4b4a6bbf0af1f5ea5ca78dae66435c41a047e042. The old demo still prints 19; it is retained as provenance rather than the maintained import role.
