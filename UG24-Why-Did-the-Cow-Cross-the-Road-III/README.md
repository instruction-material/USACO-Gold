# CircleCross native Gold practice

This optional Unit 4 practice has separate unfinished learner and preserved
completed-reference roles. Each role contains Main.java, a complete guide
and the sample fixture. Read the learner guide, predict the sample, complete
the marked tasks and retain the attempt before comparing the reference.

- [Learner contract, tasks and native workflow](starter/README.md)
- [Preserved reference and comparison workflow](solution/README.md)

Native acceptance: `python3 tests/verify-ordering-packs.py` from the source
repository root, with a JDK 17 or newer. Hosted checks repeat JDK 17 and 21.
Presence of these files does not establish an accepted site import; promote
the catalog action only after source and browser workflow acceptance.
