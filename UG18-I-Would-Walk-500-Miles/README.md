# Maximum-spacing groups from an implicit complete graph

Optional clustering application after MST cut reasoning. The goal is the largest possible minimum distance between groups, rather than the smallest total tree cost. It keeps the historical implicit-graph approach; the derived formula is a later comparison.

The [learner guide](starter/README.md) and [reference guide](solution/README.md) each include the complete contract, sample, tasks, invariant, changed-case checks and native commands. Preserve the learner attempt before reference comparison. Source origin: [USACO, US Open 2019 Gold, problem 2](https://usaco.org/index.php?page=viewproblem2&cpid=946).

The distinct starter contains four unfinished algorithm tasks. The historical reference algorithm remains intact; original working bytes are archived under `legacy/`, outside IDE role imports. Native source acceptance does not establish site-import readiness.
