# Ordered tickets and lexicographic shortest paths

Optional historical bridge practice after weighted shortest paths. It combines directed ticket portions with money-first, flight-count-second comparison. It complements core Dijkstra; it does not replace the Gold spine.

The [learner guide](starter/README.md) and [reference guide](solution/README.md) each include the complete contract, sample, tasks, invariant, changed-case checks and native commands. Preserve the learner attempt before reference comparison. Source origin: [USACO, January 2015 Silver, problem 2](https://usaco.org/index.php?page=viewproblem2&cpid=512).

The distinct starter contains four unfinished algorithm tasks. The historical reference algorithm remains intact; original working bytes are archived under `legacy/`, outside IDE role imports. Native source acceptance does not establish site-import readiness.
